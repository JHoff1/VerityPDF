# VerityPDF v0.1.30

This maintenance release improves compression previews, conversion reliability,
and background OCR handling.

- Compression previews reuse loaded PDFs when navigating between pages, reducing
  repeated loading and worker creation for large documents.
- Conversion checks selected file sizes before reading their contents and rejects
  excessively large PNG dimensions before decoding.
- Stopping PDF-to-PNG conversion now cancels an active page render and releases
  its resources.
- Background OCR prepares its page image before submitting a worker job and
  releases temporary canvases when canceled or completed.
- Updated Tauri, frontend dependencies, and Vite with its compatible React plugin.
  Patched development-tool security advisories and expanded regression tests.

All document processing remains local. Download the installer for your operating
system below; checksums and the software bill of materials are included.
