# VerityPDF v0.1.29

## What's new

- **More useful PDF compression.** Choose Lossless, Balanced, or Strong image compression. For complex vector-heavy PDFs, optionally create a separate image-only copy at 200 or 300 DPI. Compare first-page size estimates, measured final sizes, and before/after previews before saving.
- **PDF and PNG conversion.** A dedicated wizard exports PDF pages as PNG images (or a ZIP for multiple pages) and combines PNG images into a PDF.
- **Clearer page selection.** Browse without selecting pages, select multiple pages with checkboxes or keyboard modifiers, and clear all selections. Page-edit actions clearly identify how many pages they affect.
- **Keep your place.** Page edits preserve your zoom and reading position. Deleting a page shows the nearest survivor, while action messages offer Undo.
- **Faster page deletion.** Surviving pages reuse their existing rendering instead of reloading the entire PDF.
- **More reliable Windows upgrades.** Installer compatibility now handles older SovereignPDF registry locations and preserves verified custom installation folders.
- **Interface polish.** Improved selection-control alignment, file-toolbar spacing, and scrolling behavior that keeps the top toolbar visible.

Rasterized copies are image-only: text is no longer selectable, forms and annotations become permanent, and links, bookmarks, attachments, and original metadata are not carried over. This mode is opt-in, refuses signed PDFs, and never overwrites an existing file in the desktop app. Preserve-original compression remains the default.

All processing stays on your device. Download the installer for your operating system below. `SHA256SUMS.txt` and the software bill of materials are included with the release.
